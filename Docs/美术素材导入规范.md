# 美术素材导入规范

> 给美术和负责搭场景的人。按这个来，后面接程序不会返工。

---

## 1. 导出要求（最重要的一条）

**每张道具图请裁到内容边界再导出**（去掉四周的透明留白）。

原因：游戏里用"脚点 y"决定前后遮挡（`YSort`），而脚点取的是 image 的 pivot。
图带一堆透明留白时，pivot 会落在留白里，遮挡就会算错。

- 如果能裁紧 → Unity 里 `Pivot = Bottom Center` 就是对的，什么都不用调
- 如果暂时裁不了 → 用 `工具 → 美术 → 2. 把 Pivot 设到内容底部中点` 批量修

## 2. 现有素材的实际情况（已核对）

| 关卡 | 结构 |
|---|---|
| 第一关 | `IMG_1868.png` = 整间房背景（255×255 不透明），其余 32 张 = 单个道具（同样 255×255，物体在画布里的位置随意） |


## 4. Unity 导入设置

选中所有图 → Inspector：

| 设置 | 值 | 说明 |
|---|---|---|
| Texture Type | Sprite (2D and UI) | |
| Pixels Per Unit | **25** | 255px 背景 = 10.2 世界单位高；36px 角色 = 1.44 高 |
| Filter Mode | **Point (no filter)** | 像素画必须关过滤 |
| Compression | **None** | 压缩会出色块 |
| Mipmap | 关 | 2D 用不到 |

嫌一项项点麻烦：`工具 → 美术 → 1. 设为像素画 Sprite 导入设置`，选文件夹一键应用。

> PPU 如果想统一改，改 `Assets/Editor/SpriteImportTools.cs` 顶部的 `PixelsPerUnit` 常量。

## 5. Pivot

| 素材 | 怎么设 |
|---|---|
| 道具（单图） | `工具 → 美术 → 2. 把 Pivot 设到内容底部中点` |
| 角色（4 帧精灵表） | Sprite Editor → Slice → Grid By Cell Size `36×36` → **Pivot 选 Bottom Center** |
| 背景 | 无所谓（不挂 YSort） |

⚠️ **先跑工具再摆场景**。pivot 改了以后，场景里已经摆好的物体会"移位"（因为锚点变了）。

## 6. 哪些图要挂 YSort

| 素材 | 挂 YSort？ |
|---|---|
| 背景 | ❌ 固定 `Sorting Order = -1000` |
| 玩家走到后面会被挡住的家具/道具 | ✅ |
| 地毯、地贴、挂墙的画 | ❌ 给固定 `Sorting Order`，或用 `YSort.sortBias` 调 |

## 7. 命名

现在全是 `IMG_18xx` 这种相机导出名，看不出是什么。建议改成用途名：

```
bed_double.png / sofa.png / piano.png / stairs.png / photo_frame.png
```

程序排查问题和校验工具报错时能直接认出来。
